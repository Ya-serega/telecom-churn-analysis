## 🎯 Цель проекта

Анализ факторов оттока клиентов телеком-оператора для формирования рекомендаций по удержанию клиентов и снижения churn rate.

- ✅ Разведочный анализ (EDA)
- ✅ Визуализация и дашборды
- ✅ SQL-анализ
- ✅ Бизнес-рекомендации

---

## 🔍 Ключевые инсайты

| Инсайт | Значение |
|--------|----------|
| Общий уровень оттока | ~26% |
| Отток: Month-to-month контракт | ~42% |
| Отток: 2-year контракт | ~3% |
| Средний tenure ушедших | ~17 месяцев |
| Средний tenure оставшихся | ~36 месяцев |

---

## 💡 Рекомендации бизнесу

1. **Внедрить программу лояльности** для клиентов на помесячном тарифе (скидки после 6 месяцев)
2. **Автоматизировать триггерные сообщения** на 60-й день после подключения
3. **Предлагать бесплатные доп. услуги** новым клиентам в первые 3 месяца
4. **Провести опрос ушедших клиентов** с высоким ARPU для понимания причин
5. **Рассмотреть переход на автоплатёж** как фактор удержания (снижает отток на 15%)
