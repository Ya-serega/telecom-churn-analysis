# Telecom Customer Churn Analysis

Анализ оттока клиентов телеком-оператора на датасете **Telco Customer Churn**.
Проект показывает полный цикл data analysis: загрузку и очистку данных, EDA, поиск факторов оттока, интерпретацию результатов в бизнес-контексте и визуализацию ключевых выводов.

## О проекте

Цель проекта — понять, **какие характеристики клиентов связаны с высоким риском ухода**, и сформулировать практические рекомендации для снижения оттока.

В проекте выполнены:

* первичный осмотр данных;
* очистка и предобработка;
* создание аналитических признаков;
* исследовательский анализ данных (EDA);
* анализ оттока по категориям и числовым признакам;
* корреляционный анализ;
* формирование бизнес-инсайтов и рекомендаций;
* построение визуализаций и дашборда.

## Данные

Используется датасет **Telco Customer Churn Dataset** из Kaggle.
````text
https://www.kaggle.com/datasets/vedatgul/telco-churn-dataset
````

### Основные характеристики

* **7,043** записи о клиентах;
* **21** признак;
* целевая переменная — **`Churn`**;
* предметная область — телекоммуникационные услуги и удержание клиентов.

### Группы признаков

* **Демография:** `gender`, `SeniorCitizen`, `Partner`, `Dependents`
* **Услуги:** `PhoneService`, `InternetService`, `StreamingTV` и другие
* **Платежи:** `Contract`, `PaymentMethod`, `MonthlyCharges`, `TotalCharges`
* **Целевая переменная:** `Churn` (ушёл клиент или остался)

## Основные выводы

### 1. Уровень оттока высокий

Доля оттока составляет **26.54%** — это **1,869 клиентов из 7,043**. Для телеком-сегмента это значимый показатель, который напрямую влияет на выручку.

Оценка финансового эффекта показывает, что при среднем чеке около **$65/мес** годовые потери могут достигать **~$1.46 млн**.

### 2. Самый рискованный сегмент — новые клиенты

Наибольший отток наблюдается у клиентов со сроком обслуживания **0–12 месяцев**. В проекте этот сегмент рассматривается как ключевая зона риска.

### 3. Помесячный контракт связан с высоким оттоком

Сегмент **`Month-to-month`** показывает отток **42.71%**, тогда как у клиентов с двухлетним контрактом отток падает до **2.83%**.

Это один из самых сильных практических инсайтов проекта: **долгосрочный контракт значительно снижает вероятность ухода**.

### 4. Способ оплаты влияет на удержание

Клиенты с **`Electronic check`** уходят заметно чаще, чем пользователи автоматических платежей. Автоплатёж связан с более низким оттоком и является важным рычагом удержания.

### 5. Сильнейший числовой предиктор — `tenure`

Корреляционный анализ показал, что наиболее сильная связь с оттоком наблюдается у признака **`tenure`**: чем дольше клиент пользуется услугой, тем ниже риск ухода.

## Очистка и предобработка

В рамках подготовки данных были выполнены следующие шаги:

* обработаны скрытые пропуски в `TotalCharges`;
* исправлены типы данных;
* целевая переменная `Churn` преобразована в формат `0/1`;
* категориальные признаки приведены к типу `category`;
* удалены дубликаты (не обнаружены);
* созданы новые признаки для анализа.

### Созданные признаки

* **`tenure_group`** — сегментация клиентов по сроку жизни;
* **`avg_monthly_charge`** — средний платёж за месяц;
* **`num_services`** — количество подключённых услуг.

После очистки датасет стал готов к EDA: пропусков и дубликатов не осталось.

## Бизнес-инсайты

На основе анализа были сформулированы следующие выводы:

1. **Критический период — первые 10–12 месяцев.**
   Почти половина ушедших клиентов покидает сервис в первый год.

2. **Помесячный контракт повышает риск оттока.**
   Это сигнал, что клиент недостаточно «зафиксирован» в сервисе.

3. **Ручные платежи — зона риска.**
   Переход на автоплатёж может стать одним из самых простых и эффективных способов удержания.

4. **Наличие дополнительных услуг снижает риск ухода.**
   Чем больше клиент вовлечён в продуктовую экосистему, тем выше его лояльность.

## Рекомендации бизнесу

### Приоритет 1: Удержание новых клиентов

* предлагать скидку при переходе на долгосрочный контракт;
* отправлять триггерные сообщения на 30/60/90 день после подключения;
* давать персональные офферы в первые месяцы обслуживания.

### Приоритет 2: Стимулирование автоплатежа

* сделать подключение автоплатежа проще;
* предлагать бонус или скидку за переход на автоплатёж;
* добавлять напоминания для клиентов с ручной оплатой.

### Приоритет 3: Мониторинг и A/B-тесты

* отслеживать отток по сегментам еженедельно;
* тестировать офферы для новых клиентов;
* регулярно анализировать причины ухода.
